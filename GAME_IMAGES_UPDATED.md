## Customization

To replace any game image:

1. Find a gaming image on Unsplash
2. Copy the photo ID from URL (e.g., `photo-XXXXXXXX`)
3. Update in `app/page.tsx`:
   ```typescript
   image: 'https://images.unsplash.com/photo-XXXXXXXX?w=800&q=80'
   ```
