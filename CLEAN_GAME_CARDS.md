## Customization Options

To change any game image:

1. Find a game image on Pexels or Unsplash
2. Copy the image URL
3. Update in `app/page.tsx`:
   ```typescript
   image: 'https://images.pexels.com/photos/XXXXX/pexels-photo-XXXXX.jpeg?auto=compress&cs=tinysrgb&w=800'
   ```
